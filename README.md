# WorkOut_Budy

M: MongoDB(DB)
E: Express(Backend)
R: ReactJs(Frontend)
N: NodeJs(Backend)

## FrontEnd (Client/Browser Side)        Backend (Server)           DB()
        React App                        ExpressJs+NodeJs          MongoDB

## Backend :-
# npm init -y :- this cmd is use for the to get the package.json and all the node files    
# npm install express / npm i express :- this cmd is use for download the express
# npm i -g nodemon :- this cmd is use for the install the nodemon    
# npm i dotenv
# npm i mongoose

Run the application:- npm run dev       


## API ENDPOINT
get method      /workouts --> get all the workout doc.
post            /workouts --> create a new workout doc.
get             /workouts/:id --> single workout doc.
delete          /workout/:id --> delete a single workout doc.
patch           /wokouts/:id -->update a single workout.

## Frontend :-
# npx create-react-app frontend


## How to run 
open the backend folder and open the integrated terminal and run cmd :- "npm run dev"
open the frontend folder and open the integrated terminal and run cmd :- "npm start"
